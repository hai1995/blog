## 前言

九九乘法表是我们小时候必学的内容，也是编程入门必经的练习题之一。在 Python 中，我们可以使用嵌套循环轻松实现它。

## 代码实现

```python
# 九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{j}×{i}={i*j}', end='\t')
    print()
```

## 代码解析

1. **外层循环** `for i in range(1, 10)`：控制行数，从 1 到 9
2. **内层循环** `for j in range(1, i + 1)`：控制每行的列数，最大值为当前行数 `i`
3. **`end='\t'`**：使用制表符分隔，替代默认的换行
4. **`print()`**：每行结束后换行

## 使用 while 实现

```python
i = 1
while i < 10:
    j = 1
    while j <= i:
        print(f'{j}×{i}={i*j}', end='\t')
        j += 1
    print()
    i += 1
```

## 总结

本文涉及的主要知识点：

- **嵌套循环**：外层循环控制行，内层循环控制列
- **range() 函数**：生成数字序列
- **print() 参数**：`end` 参数控制结尾字符
